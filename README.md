# Enhanced 3D Art Gallery - Portfolio Project

A stunning, feature-rich 3D art gallery built with Three.js featuring advanced particle systems, dynamic lighting modes, and professional-grade visual effects. This project showcases 5 different artworks from Unsplash in a realistic gallery environment with cutting-edge web technologies.

## LIVE PREVIEW: https://statuesque-bavarois-536333.netlify.app/

## ✨ Enhanced Features

### **Advanced Visual Effects**
- **Particle System**: 1000+ animated particles with customizable count, speed, and size
- **Dynamic Lighting Modes**: Normal, Warm, and Cool lighting presets with smooth transitions
- **Atmospheric Fog**: Realistic depth and atmosphere with toggleable fog effects
- **Rim Lighting**: Dramatic edge lighting for enhanced visual depth
- **Glow Effects**: Subtle glow around canvas frames for premium feel

### **Professional Controls**
- **Camera Presets**: Overview, Close View, and Side View with smooth transitions
- **Particle Controls**: Real-time adjustment of particle count, speed, and size
- **Lighting Controls**: Toggle lights, cycle through lighting modes
- **Effect Toggles**: Particles, fog, auto-rotate, and sound controls
- **Performance Stats**: Real-time FPS counter and particle count display

### **Enhanced User Experience**
- **Smooth Animations**: Eased camera transitions and fluid particle movement
- **Interactive UI**: Modern control panels with hover effects and smooth transitions
- **Fullscreen Support**: Immersive fullscreen gallery experience
- **Responsive Design**: Optimized for desktop and mobile devices
- **Professional Styling**: CV-ready presentation with advanced CSS effects

## 🎮 Advanced Controls

### **Navigation**
- **Mouse Drag**: Rotate camera around the gallery
- **Mouse Wheel**: Zoom in/out
- **Mouse Pan**: Move camera position

### **Camera Presets**
- **Overview**: Wide-angle view of entire gallery
- **Close View**: Intimate close-up of artworks
- **Side View**: Side perspective for different angle

### **Lighting & Effects**
- **Toggle Lights**: Turn all lighting on/off
- **Cycle Mode**: Switch between Normal, Warm, and Cool lighting
- **Toggle Particles**: Enable/disable particle system
- **Toggle Fog**: Add/remove atmospheric fog effect
- **Auto Rotate**: Enable smooth automatic camera rotation

### **Particle System**
- **Count Slider**: Adjust particle count (100-5000)
- **Speed Slider**: Control particle movement speed
- **Size Slider**: Modify particle size
- **Real-time Stats**: Live FPS and particle count display

### **Additional Features**
- **Reset View**: Return to default camera position
- **Fullscreen**: Enter immersive fullscreen mode
- **Sound Toggle**: Audio controls (ready for implementation)

## Technical Implementation

- **Three.js**: 3D graphics library for WebGL rendering
- **OrbitControls**: Smooth camera navigation
- **Texture Loading**: Asynchronous image loading with error handling
- **Shadow Mapping**: Realistic shadows and lighting
- **Responsive Design**: CSS Grid and Flexbox for modern layout

## Getting Started

1. Open `index.html` in a modern web browser
2. Wait for the gallery to load (loading screen will appear)
3. Use mouse controls to navigate around the gallery
4. Explore the different artworks and lighting effects
